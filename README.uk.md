# Пропорційний перехід курсора для KWin

[English](README.md) · **Українська**

Нативний ефект для Plasma Wayland. На спільному краї двох екранів зберігає відносну висоту курсора, а для екранів один над одним — відносну ширину. Працює і з тієї частини краю більшого екрана, де стандартний курсор зупиняється. Якщо з одного боку кілька екранів, вибирає найближчий до точки перетину.

Пропорційний перехід також діє під час переміщення вікна між екранами. Під час зміни розміру вікна, інших перетягувань із затиснутою кнопкою, блокування сеансу та захоплення або обмеження курсора програмою діє звичайна поведінка KWin.

## Встановлення у Fedora

З каталогу проєкту виконай:

```bash
sudo dnf install libdnf5-plugin-actions gcc-c++ cmake extra-cmake-modules kwin-devel qt6-qtbase-devel qt6-qtdeclarative-devel kf6-kcoreaddons-devel libdrm-devel libepoxy-devel wayland-devel
./install.sh
```

Запускай інсталятор від свого користувача в сеансі Plasma. Для вимкнення виконай `./install.sh --disable`, для повторного ввімкнення — `./install.sh --enable`.

Після оновлення пакета `kwin` через DNF5 служба systemd автоматично перезбирає ефект. Поточний сеанс може використовувати попередню збірку до наступного входу в Plasma. Під час запуску системи служба також перевіряє версію KWin і наявність плагіна та за потреби повторює збірку. Журнал доступний через `journalctl -u kwin-relative-pointer-rebuild.service`.
